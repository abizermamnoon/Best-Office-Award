# Birthday award website

Open index.html in a browser, keeping app.js in the same directory.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload index.html and app.js to the root of the main branch.
3. In Settings → Pages, choose Deploy from a branch, main, / (root), then Save.
4. GitHub will display the website link when publication finishes.

Name matching ignores letter case and repeated spaces. For Abraham, enter “Abraham” and “Tamru Assefa” in the two fields (or “Abraham Tamru” and “Assefa”). All five names are matched as full names.

The Thomas sequence is a visual prank only. It never downloads files, requests permissions, or accesses the device. Its messages appear immediately, after one second, and after one further second. Browser scheduling may delay timers when the tab is in the background.

This version uses browser-side JavaScript so it works on static hosting. Names and the surprise are visible in the source; name entry is not authentication. No names are sent or saved. Google Fonts may be requested for typography; system fonts are used offline.
